# 📨 Disparo em Massa via WhatsApp – Node.js + Green API

Este projeto é uma aplicação Node.js para envio automatizado de mensagens em massa via **WhatsApp**, utilizando a **Green API** (integração oficial com WhatsApp Business). A lista de contatos é lida a partir de um arquivo **CSV**, permitindo o envio de mensagens personalizadas para múltiplos destinatários de forma prática e escalável.

---

## ✅ Funcionalidades

- Envio de mensagens em massa via **Green API**
- Leitura de contatos a partir de arquivos `.csv`
- Personalização de mensagens (nome, saudação, etc.)
- Controle e logs de mensagens enviadas
- Fácil integração com outros sistemas

---

## 🛠 Tecnologias Utilizadas

- Node.js
- Green API (WhatsApp Business)
- Axios (requisições HTTP)
- fs / csv-parser (leitura de arquivos)
